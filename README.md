# Swiggy Restaurant Analysis Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyze Swiggy restaurant data, including ratings, prices, delivery time, and city-wise performance.

## Key Features
- KPI cards for restaurant insights.
- City-wise restaurant filtering.
- Restaurant price and rating analysis.
- Interactive charts and visualizations.
- Customer rating trends and distribution.

## Tools Used
- Microsoft Power BI
- Data Visualization
- Data Analysis

## Objective
To analyze restaurant data, identify rating trends, explore price distributions, and understand city-wise restaurant performance through interactive visualizations.
